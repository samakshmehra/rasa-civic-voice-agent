# FAQ reference material — invented

The content here is **fictional**. It describes how complaints are handled by
"Civico Demo Municipal Services", which does not exist. Process steps,
escalation paths and timeframes were written for a demo and match no real
municipality's published procedure.

It is retrieved and quoted by the `civic_faq` skill, so anything inaccurate
here is read out to the caller as fact. That is why it stays deliberately
generic: it explains how *this demo* works, and says so.
